
Для доступа к админке создайте администратора командой `python manage.py createsuperuser`, затем откройте http://127.0.0.1:8000/admin/.

## Страницы

- `/` — главная и услуги.
- `/services/` — каталог услуг с динамическим поиском.
- `/login/` — вход в личный кабинет.
- `/register/` — регистрация клиента (ФИО, телефон, email, пароль).
- `/profile/` — личный кабинет и последние заказы.
- `/orders/` — список заказов текущего клиента (для сотрудника — все заказы).
- `/orders/new/` — оформление заявки.
- `/orders/<id>/` — карточка заказа и акт осмотра.
- `/staff/orders/<id>/inspection/` — рабочее место сотрудника для создания/обновления акта.
- `/about/` — как это работает и контакты.

## Дизайн и адаптивность

Стили собраны в `static/css/main.css`. Основные цвета соответствуют PDF-макету: фон `#F7F7F2`, текст `#252923`, зелёный акцент `#4E5E43`, светло-зелёные поверхности `#E8ECE2`.

Макет адаптируется для ширин 360/375, 768, 1024 и 1440 px. На мобильных экранах навигация сворачивается в меню, карточки и формы переходят в одну колонку, кнопки растягиваются на ширину контейнера.

## Структура

- `config/` — настройки и корневые URL Django.
- `laundry/` — модели, формы, представления, маршруты и админка.
- `templates/` — HTML-шаблоны.
- `static/css/main.css` — стили интерфейса.
- `static/js/main.js` — мобильное меню, клиентская проверка форм и поиск услуг через fetch.
- `fixture_laundry_data.json` — демонстрационные данные.
